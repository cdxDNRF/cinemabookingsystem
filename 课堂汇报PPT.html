项目介绍

  • 一个功能完整的电影购票系统，支持多影院、多影厅、多场次管理
  • 三种角色：超级管理员、影院管理员、普通用户
  • 核心功能：在线选座购票、锁座超时释放、数据统计分析
  • 前后端完全分离架构，易于扩展和维护
2 / 12

技术栈

后端

  • Spring Boot 3
  • MyBatis
  • MySQL 8.0
  • Hutool 工具库
  • Lombok
  • JWT 鉴权

前端

  • Vue 3 + TypeScript
  • Element Plus
  • Vue Router
  • Pinia
  • Axios
  • ECharts
3 / 12

项目结构

后端 cinema-backend

  • auth: 认证模块
  • common: 公共组件
  • module: 业务模块
  • config: 配置

前端 cinema-frontend

  • pages: 页面组件
  • api: API 接口
  • stores: 状态管理
  • router: 路由

数据库：14 张表，含外键约束和初始化数据
